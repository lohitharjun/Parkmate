# ParkMate frontend starter

React + Vite starter for the ParkMate parking marketplace.

## Run on Windows
1. Install Node.js LTS: https://nodejs.org/en/download
2. Extract this ZIP to a folder such as `C:\Users\2024\ParkMate`.
3. Open the folder in VS Code, then choose Terminal → New Terminal.
4. Run `npm install`
5. Run `npm run dev` and open the localhost URL printed in the terminal (usually http://localhost:5173).
6. Check production compilation with `npm run build`.

## Important prototype limits
Listings and bookings currently use sample data in browser memory. They reset when the page refreshes. This starter does not yet have real authentication, database persistence, payment processing, live traffic, or production booking APIs. Do not enter real passwords or sensitive information.
