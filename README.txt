ParkMate website package

Page flow:
1. index.html — welcome / first page
2. landing-page.html — ParkMate marketing landing page
3. dashboard.html — ParkMate app

Keep all three HTML files in the same folder. Open index.html to start.
For deployment, upload all three files to the same website directory. The dashboard app
may rely on its configured backend/authentication services; this package preserves the
provided app build and does not replace those services.
